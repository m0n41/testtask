# Отчёт по выплатам подрядчикам

Я подготовил небольшой скрипт, который читает три CSV-файла из `data/` и показывает по каждой работе цену, чистую выплаченную сумму и остаток. В конце он выводит сводку по договорам. Деньги считаются через `Decimal`, без потери копеек.

## Запуск

Нужен Python 3.9 или новее; сторонние пакеты устанавливать не нужно. Из папки проекта выполните:

```powershell
python report.py --as-of 2026-11-10
```

Для другой даты передайте её в формате `ГГГГ-ММ-ДД`. По умолчанию данные читаются из `data/`. Другую папку можно указать параметром `--data-dir`, например:

```powershell
python report.py --as-of 2026-11-10 --data-dir C:\путь\к\data
```

В сводке есть и остаток по активным работам, и остаток от суммы договора. Эти значения могут различаться: отменённая работа уменьшает сумму работ к оплате, но сама по себе не меняет сумму подписанного договора. Очередь на оплату не считается уже выплаченной.

Правила расчёта и принятые допущения описаны в [DECISIONS.md](./DECISIONS.md), короткая записка бухгалтеру — в [ACCOUNTANT_NOTE.md](./ACCOUNTANT_NOTE.md).
